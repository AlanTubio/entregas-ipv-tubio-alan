# Entrega 4 - Desarrollo de Videojuegos


[**Jugar demo**](https://alantubio.github.io/demo-desarrollo-de-video-juegos-UNQ/entrega-4-tubio-alan/index.html)

## Controles

| Acción | Tecla |
| --- | --- |
| Moverse | `A` / `D` o flechas izquierda / derecha |
| Saltar | `W`, `Espacio` o flecha arriba |
| Disparar | Clic izquierdo |
| Reiniciar el nivel | `R` |
| Mostrar el área de detección enemiga | `T` |

## Tecnología

- Godot 4.7
