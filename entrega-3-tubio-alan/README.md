# Entrega 3 - Tubio Alan

[Play](https://alantubio.github.io/entregas-ipv-tubio-alan/entrega-3-tubio-alan/docs/)

## Controles

- **A / Flecha izquierda**: moverse a la izquierda
- **D / Flecha derecha**: moverse a la derecha
- **W / Espacio / Flecha arriba**: saltar
- **Botón izquierdo del mouse**: disparar el cañón
