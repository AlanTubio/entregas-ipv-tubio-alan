# Dodge the Creeps!

Sobreviví el mayor tiempo posible mientras esquivás enemigos!!

## Jugar

[Jugar ahora](https://alantubio.github.io/demo-desarrollo-de-video-juegos-UNQ/entrega-0-tubio-alan/index.html)

## Controles

| Acción          | Teclado                  |
| --------------- | ------------------------ |
| Mover arriba    | `W` o `Flecha arriba`    |
| Mover abajo     | `S` o `Flecha abajo`     |
| Mover izquierda | `A` o `Flecha izquierda` |
| Mover derecha   | `D` o `Flecha derecha`   |
| Iniciar partida | `Enter` o botón `Start`  |

## Cómo jugar

1. Abrí el enlace de arriba.
2. Presioná `Enter` o el botón `Start`.
3. Esperá la cuenta regresiva y mové al personaje para esquivar a los enemigos.
4. Intentá conseguir el puntaje más alto posible.

## Tecnología

- Godot Engine 4
